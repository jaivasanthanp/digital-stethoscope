    How this works (and limits)

    This page uses two web APIs that Chrome on Android (≥ 56) supports: Web Audio for the mic, Web Bluetooth for the GATT connection to the nRF52840 DK. The whole flow runs locally on your phone — nothing is uploaded to a server. iOS Safari does not support Web Bluetooth; use Bluefy or a Bluetooth-enabled browser on iOS, or stick to Android Chrome.

    The phone writes int16 PCM windows to characteristic 12345678-1234-1234-1234-123456789ABE on the HeartSound peripheral. Classifications come back as ASCII notifications on 12345678-1234-1234-1234-123456789ABD.
